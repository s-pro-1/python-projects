# Project 03 - Password Generator

## Description

A command-line password generator written in Python.

The program creates random passwords based on the user's choices.
The user can choose the password length and what types of characters
to include.

## Features

- Generate random passwords
- Choose password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include symbols
- Validate user input
- Generate multiple passwords without restarting the program

## Concepts Practiced

- Python modules
- `random` module
- `string` module
- Variables
- User input
- `if` statements
- `for` loops
- `while` loops
- `try/except`
- String manipulation

## How It Works

1. The user enters the desired password length.
2. The user chooses which character types to include.
3. The program builds a character pool.
4. Random characters are selected from the pool.
5. The generated password is displayed.

## How to Run

Run the program using:

```bash
python index.py ```

Example
=== Password Generator ===

Enter password length: 12

Include uppercase letters? (y/n): y
Include lowercase letters? (y/n): y
Include numbers? (y/n): y
Include symbols? (y/n): y
